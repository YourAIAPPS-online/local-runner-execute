# local-runner-execute

Prebuilt installers for the Local RAG Companion (part of [YourAIApps](https://youraiapps.online)) - macOS, Windows, and Linux.

This repo holds built binaries only, published one version per folder. Source code lives in the main product repo; this repo exists so installers can be downloaded directly, with full version history, independent of that repo's own visibility.

## Downloading

- **Latest of each platform**: see the [Releases](../../releases) page, or use the direct redirect at `rag.youraiapps.online/downloads/{mac,windows,linux}`.
- **A specific version**: browse into that version's folder (e.g. `v0.3.0/`) below.

## Layout

```
v0.3.0/
  Local-RAG-Companion-macOS-arm64.dmg
  Local-RAG-Companion-windows-x64.zip
  Local-RAG-Companion-linux-x64.tar.gz
  release.md   - what changed and what's included in this version
```

Each version is also published as a [GitHub Release](../../releases) with the same three files attached, for anyone who prefers that download flow or wants update notifications.
